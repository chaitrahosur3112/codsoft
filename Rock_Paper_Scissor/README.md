# Rock Paper Scissors Game

A simple **Rock-Paper-Scissors web game** built using **Python Flask** where a user plays against the computer. The computer randomly selects a move and the system determines the winner instantly.

---

##  Features

* Interactive **web interface**
* **Random computer selection**
* Instant **game result display**
* Backend built with **Flask API**
* Simple **game logic implementation**

---

## Technologies Used

* Python
* Flask
* HTML
* CSS
* JavaScript

---

## Installation

1. Clone the repository

```bash
git clone https://github.com/yourusername/rock-paper-scissors.git
cd rock-paper-scissors
```

2. Install Flask

```bash
pip install flask
```

3. Run the application

```bash
python app.py
```

4. Open in browser

```
http://127.0.0.1:5000
```

## Game Rules

* Rock beats Scissors
* Scissors beats Paper
* Paper beats Rock

The computer randomly selects a move and the server returns the result using a Flask API.
